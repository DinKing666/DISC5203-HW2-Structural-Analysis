# DISC 5203 - Homework 2

This repository is an independent Homework 2 submission derived from the accepted Homework 1 Git history. The two assignments are separated so instructors can inspect either submission without unrelated files mixed into its working directory.

## Repository layout

- [`HW2/`](HW2/) - the complete Homework 2 submission: assignment input, configuration, plain-language briefings, OpenSees models, scripts, generated results, figures, Markdown report, and PDF report.
- [`HW1_reference/`](HW1_reference/) - an unchanged snapshot of the accepted Homework 1 files used as the starting geometry and axial-load reference.

Start with [`HW2/README.md`](HW2/README.md). The primary submission is [`HW2/report/21345221_HW2_report.md`](HW2/report/21345221_HW2_report.md), with a convenience PDF at [`HW2/output/pdf/21345221_HW2_report.pdf`](HW2/output/pdf/21345221_HW2_report.pdf).

The Git history retains the original HW1 commits and the subsequent HW2 development, satisfying the requirement that HW2 build on rather than re-derive the HW1 work.
